# Shared assets

Brand and media used by both newsletters and presentations.

| Folder | Purpose |
|--------|---------|
| `assets/` | Logos, icons, photos (copy or symlink into project-specific `assets/` as needed) |
| `brand/` | Reference colors, typography notes (`colors.css` is not inlined into email — use as a guide) |

Keep one source of truth here so campaigns and decks stay visually consistent.
